# Project instructions

This repository is a Frontier Engineering Challenge entry. Follow the role
prompts in `.agents/` and keep the work evidence-first.

- Do not make high-impact or external actions without explicit human approval.
- Use only public, synthetic, or approved data; never commit secrets.
- Preserve the baseline and advanced workflows with the same evaluation cases.
- Store reproducible evaluation artifacts and redacted agent trajectories in
  version-controlled project directories once the project scaffold exists.
- Document every material iteration, including experiments that were removed.
